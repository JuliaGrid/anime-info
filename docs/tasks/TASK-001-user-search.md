# User Story: Я, как пользователь, хочу искать аниме, чтобы найти нужное 

## Сценарий: 

1. Пользователь заходит на страницу Поиска 

2. Вбивает название аниме в поисковую строку 

3. Нажимает Enter/кнопку “искать” 

4. Появляется список аниме, совпадающих по названию 

## Критерии приемки: 

1. На странице имеется поле ввода 

2. На странице имеется кнопка “искать” 

3. В поле ввода можно вводить буквы, цифры, другие символы 

4.После ввода названия аниме в поле ввода, по нажатию enter/нажатия на кнопку “искать” происходит поиск (запрос на бэк) 

5. Появляется loader, пока бэк не пришлет ответ 

6. При успехе - появляется список карточек аниме, имеющих совпадение в названии 

    6.b При отсутствии совпадений - показывается текст “Нет подходящих аниме” 

    6.c При ошибке на бэкенде - страница НЕ ломается - показывается текст “Ошибка на сервере” 

7. Список аниме имеет пагинацию, по 10 карточек на странице
